# Василий против пришельцев: Новохмуринский Квакокалипсис 🐸💥

> **Постсоветский дизельпанк top-down / 2.5D экшен-рогалик.**  
> В роли сантехника-кулибина Василия защитите умирающий моногород Новохмуринск от инопланетного вторжения боевых кибер-жаб.

![Геймплей в городе](docs/gameplay_city.png)

---

## 📖 Концепция и Идея

**Сеттинг**: Позднесоветский провинциальный моногород Новохмуринск, затерянный среди заводов, гаражных кооперативов и панельных хрущевок. На город обрушился метеорит с космической расой разумных кибернетических земноводных — **Болотной Империей Квак'Тулху**.

**Главный герой**: **Василий** — простой русский мужик, ветеран сантехники и гаражной инженерии. Вооружившись дедовским обрезом, самодельной рукой-перфоратором и силой народного духа, Василий встает на защиту родного района.

### Ключевые столпы игры:
1. **Аутентичный постсоветский дизельпанк**:
   - Панельные дома с жестяными козырьками и светящимися окнами.
   - Гаражи с распашными воротами, разбитые «Жигули» и «Буханки» скорой помощи.
   - Опорный пункт цивилизации — круглосуточный ларек **«У Михалыча»** под защитным энергетическим куполом.
2. **Гибридный 2.5D движок (Canvas 2D + Three.js WebGL)**:
   - Высокодетализированный процедурный мир 4000x4000 с бесшовным текстурированным асфальтом, тротуарной плиткой и чугунными люками.
   - Полностью трехмерные модели Василия и врагов со skeletal animation, кинематическим расчетом прицеливания и оффскрин-кэшированием для 60 FPS.
3. **Глубокая RPG-система и крафт**:
   - 3 взаимоисключающие ветки развития: **Кулибин** (дизельпанк-технологии), **Шаман гаражей** (народная магия и аура перегара), **Киборг Вторжения** (инопланетные мутации).
   - Лут из тайников: крышки, запчасти, тушенка, бинты, водка.

## 🎮 Управление

| Клавиша / Действие | Функция |
|---|---|
| **W, A, S, D** | Передвижение по городу |
| **Мышь** | Прицеливание (360°) |
| **Левая кнопка мыши (ЛКМ)** | Стрельба / атака выбранным оружием |
| **Пробел** | Тактический перекат с кадрами неуязвимости (тратит выносливость) |
| **E** | Обыск тайников (машины, мусорки, ящики) / Вход в магазин Михалыча |
| **Q** | Следующее открытое оружие (по порядку хотбара) |
| **1–8** | Слоты хотбара: расходники (водка, тушёнка, бинты) и купленное оружие. Порядок меняется перетаскиванием слотов мышью и запоминается |
| **R** | Перезарядка ПМ и обреза |
| **ESC** | Закрыть меню магазина / пауза |
| **F3** | Оверлей производительности (FPS, время кадра) |

## 🔫 Арсенал Василия

1. **Обрез двустволки «Мечта егеря»**:
   - Сокрушительный урон дробью на ближней дистанции с конусом разлета и отдачей.
2. **Рука-перфоратор «Ударник-78»**:
   - Механический привод с вращающимся сверлом и высеканием искр при перекате и ударе.
3. **Плазменный карабин «Светлячок»**:
   - Трофейный инопланетный излучатель высокой скорострельности, стреляющий сгустками едкой плазмы.

---

## 👾 Бестиарий Болотной Империи

- **Жаба-пехотинец (Toad Grunt)**: быстрый штурмовик с кислотным бластером и бионическим глазом.
- **Жаба-снайпер (Toad Sniper)**: дальнобойный стрелок с импульсной винтовкой, держащий дистанцию.
- **Жаба-громила (Toad Brute)**: тяжелый бронированный гигант с чугунными наплечниками, огромным запасом здоровья и разрушительной поступью.

## 🚀 Запуск игры

Игра работает прямо в браузере без сборщиков и сложных зависимостей через любой локальный HTTP-сервер:

### Способ 1: Python
```bash
python -m http.server 8080
```
Затем откройте в браузере: `http://localhost:8080`

### Способ 2: Node.js (npx serve)
```bash
npx serve -l 8080
```
